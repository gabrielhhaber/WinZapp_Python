🔌 1. Getting started

WinZapp is a WhatsApp client for Windows built for people who use a screen reader (NVDA, JAWS or Narrator). It works like WhatsApp Web: your phone stays the main device and WinZapp joins as a linked device.

Install

Always download from the official repository's Releases page (github.com/gabrielhhaber/WinZapp_Python/releases). Copies on other sites are not from the project. Every release has these files:

FileWhat it is for
WinZappInstaller.exeThe installer. The right choice for most people. It installs to %LOCALAPPDATA%\WinZapp (no administrator rights needed), can create desktop and Start menu shortcuts, and registers an uninstaller in Windows Settings > Apps.
WinZapp.zipThe same program as a portable version. Extract it to a folder on a local disk and run WinZapp.exe.
SHA256SUMS.txtChecksums to verify the download.
⚠️ Local disk
WinZapp does not work from a network folder (such as \\server\folder, or the Downloads folder of a virtual machine). If that happens, it tells you and explains what to do: install with WinZappInstaller or move the folder to a disk on your own computer.

Requirements: 64-bit Windows 10 or 11, an internet connection and a WhatsApp account on your phone.

Stable or alpha

  • Stable: made by hand and recommended. It is the one marked "Latest" on the Releases page.
  • Alpha: marked "Pre-release". It is built automatically for every change on the main line, without long testing, so it may have defects. The number ends in "alpha" (for example, 2.1.0.4397alpha; the last digits count the changes made to the project).

By default you only receive stable versions. To receive alphas too, check "Check for alpha updates (unstable)" in Settings > General.

First start

The first time, WinZapp downloads and sets up by itself the components that talk to WhatsApp Web (the WPPConnect server and an internal Chromium browser). This needs internet and shows a progress window titled "Starting WPPConnect, please wait...". On later starts, with the account already connected, the main window and your chats appear right away and WhatsApp connects in the background. Messages you send in the meantime wait and go out as soon as the connection is ready. The window title shows "starting WPPConnect..." until everything is ready.

Connect your account

The connection screen offers two ways to pair:

  1. 1
    Phone number: If you have not paired yet, the "Connection engine" list before the country lets you choose between WPPConnect and Neonize without opening Settings; when you choose, WinZapp asks for confirmation and restarts with the chosen engine. choose the country (the list is alphabetical, uses the country and language of Windows, and accepts typing several letters to search), type the number and continue. WinZapp shows a code. On your phone, open WhatsApp, go to Linked devices > Link a device and choose to link with a phone number.
  2. 2
    QR code: scan the code on the screen with WhatsApp on your phone, under Linked devices.

WinZapp announces when the code is being generated, when it actually appears, when it expires and when it could not be generated. If WhatsApp refuses the code, the message explains why.

💡 Connecting a different number
Closing or cancelling the pairing screen does not delete your chats. History is only erased when a different phone number is actually connected, and in that case WinZapp warns you.

Where your data lives

Everything is in a data folder next to the program: accounts, message history, downloaded media and logs. With the installer, it is %LOCALAPPDATA%\WinZapp\data. Back up that folder if you want to take your history to another computer. Message content and the session token are stored encrypted.

Updates

WinZapp looks for new versions by itself and offers to download and install them. To check right now, use Help > Check for updates (if the update server cannot be reached, it tells you). A few useful things:

  • With "Download updates and transcription downloads in the background, without the progress window" (Settings > General), you keep using the program, connected, while the update downloads; only when it is ready does WinZapp say it is going to install. If you are on a call, the notice waits until it ends.
  • Cancelling the progress window before the installation starts stops the update safely.
  • The downloaded package is kept while it waits to install. Once WinZapp closes, wait for the installer to finish before opening it again. If installation does not finish, reaching the wait limit does not automatically reopen WinZapp. An incomplete copy is a failure; a later successful update clears the earlier failure warning. If copying fails or its completion cannot be confirmed, WinZapp stays closed and opens recovery instructions in Notepad. Wait for the installer to finish before repairing. Back up your existing data folder, repair the program files using the official installer or ZIP, and keep your data folder. The note shows the installation folder and update log location.
  • With more than one account open, the update opens a single window and closes the other accounts before installing.
  • Help > Force reinstall WPPConnect and Force reinstall from ZIP file are there for when something in the local server gets out of shape.
  • Help > What's New shows what changed in each version, and Help > "What's New Since You Last Looked..." summarizes only what is new for you, in plain sentences. The "What's new?" button in the update window shows what the offered version changes; on an alpha, it also lists the changes of each alpha since yours.

Check the download

Every release has a SHA256SUMS.txt. To check in CMD:

certutil -hashfile WinZappInstaller.exe SHA256

The value must match the one on the file's line. If it differs, delete the file and download it again. WinZapp's updater also checks the checksum (and, on newer versions, the signature) before installing.

System tray and global shortcut

WinZapp can stay in the system tray and start with Windows. There is a global shortcut (configurable in Settings > Interface > Keyboard shortcuts) that brings the window to the front from any program; with WinZapp already in the foreground, the same shortcut hides it in the tray. Spoken announcements

Everything WinZapp says goes through your screen reader (or through the Windows SAPI voice, if you enable that option in Settings > Accessibility and no screen reader is active). In Settings > Accessibility > Spoken content you choose what is announced.

💬 3. Chat list

The chat list (Alt+1) shows the names of people and groups, never internal codes. Each row reads the name, the last message and the state (unread, pinned, muted...).

Filters and lists

  • Filters: All, Unread, Groups and Individual, as radio buttons. Alt+Shift+F takes you to them; Alt+Shift+A, Alt+Shift+U, Alt+Shift+G and Alt+Shift+I pick All, Unread, Groups and Individual straight from the list.
  • WhatsApp lists: your custom lists appear before the filters. You can refresh them, filter by them, create or rename a list, and add or remove chats, in "Manage WhatsApp lists". Editing depends on your account's support; when it is not possible, the manager says why. Locked chats or chats unavailable locally do not show in the selection, and the other members of the list are preserved.
  • Search: Ctrl+F takes you to the search field; the down arrow goes to the first result. In Settings > Interface > Chats, "Keep the chat search when opening a chat" makes Esc return focus to that chat in the results instead of going back to the full list.

Open a chat

Enter opens the selected chat. Focus goes where you set it in Settings > Interface > Chats (message field, or the unread marker / last message). Esc or Ctrl+W closes the chat.

The chat context menu

ℹ️ Shortcuts can be changed
All shortcuts in this guide are the factory ones. You can change them in Settings > Interface > Keyboard shortcuts. The complete, always current list is in the Keyboard shortcuts section and on F1.

Clear and delete

  • Clear chat asks whether to keep starred messages ("Keep starred messages", checked by default). Unchecked, starred messages are deleted too, including on the phone. It also applies to several selected chats and to archived ones.
  • The clear and delete confirmations have a "Don't show again" box, which only counts together with Yes. To be asked again, use the matching options in Settings > Interface > Confirmations. With the question turned off, clearing keeps starred messages.
  • Mark all chats as read (File menu, or Ctrl+Alt+Shift+M) asks first, with No as the default. It also has "Don't show again"; the option "Ask for confirmation before marking all chats as read" brings the question back.
  • Spoken confirmation: marking a chat read or unread, muting, archiving and pinning now say what was done, and marking several chats as read says how many.

New chat, group and contact

Ctrl+N opens "New chat". There you search for a contact (the field already has focus and filters by name, including surname, and by number as you type), start a chat by number, create a group, add a contact, join a group by link and open communities ("Communities" button).

If you type a Brazilian number with the extra 9 and WhatsApp uses the number without it, the conversation stays a single one: after the first message it uses WhatsApp's number.

In a new or empty personal chat, the line that says there are no messages also tells you that messages and calls are end-to-end encrypted and, if the chat has disappearing messages, how long they last.

Contacts: local or synced with the phone

When you add a contact (in Chat info, in New chat or from a contact message), there are two tabs:

  • Contact synced with the phone: saves the name on WhatsApp and in the phone's address book. It opens by default; if the number is already in the phone's address book, only this tab appears. Deleting a synced contact also removes it from WhatsApp and from the phone.
  • Local WinZapp contact: the name exists only in WinZapp.

Verified businesses you have not saved (banks, payment apps...) appear with the business's verified name. A name saved in your contacts always takes precedence.

The conversation, archived and locked chat lists use the full width of the list, so names and message previews are cut off only when the window is narrow.

Pinning

With "Keep pinned chats in a fixed order" (Settings > Interface > Chats), new messages do not change the position of pinned chats and the order is kept on restart. Turned off, pinned chats move up with new messages like the others.

Select several chats

Ctrl+Space marks or unmarks the focused chat. After the first marked item, Space alone marks and unmarks the following ones (selection mode; the screen reader announces when it turns on and off, and it turns off when nothing is marked any more). Shift+Down/Up Arrow extends the selection, Shift+Home and Shift+End mark up to the start or the end, and Ctrl+Shift+Space marks or unmarks everything. With something marked, the first Esc only unmarks. This also applies in archived and locked chats, in the message list and in the forward window.

📨 4. Inside a chat

When you open a chat you get the message list and the message field. Each message is a row that the screen reader reads with sender, content and state.

Send messages

Type in the message field and press Enter; Shift+Enter inserts a new line. Sends go through a background queue. If WhatsApp accepts the message but does not confirm delivery, WinZapp tells you to check the chat before resending, so it is not delivered twice. Sending a message to yourself (the "Me (messages to myself)" chat) works too.

  • Emoticons become emojis as you type: :) becomes 🙂, :D becomes 😃, <3 becomes ❤️, when you type a space or punctuation after them. Backspace right after the conversion gives back what you typed. It can be turned off in Settings > General. Ctrl+. opens the emoji picker (the left and right arrows change the skin tone).
  • Spell check: a dedicated sound plays when you misspell a word, when you type punctuation after it and when the cursor reaches a misspelled word. In the field's context menu, the "Spelling" submenu offers suggestions from the Windows dictionary. In Settings you choose to follow Windows, always on or always off.
  • Mentions: type @ to pick someone (Enter inserts the mention, Esc closes). In groups, @all works too.

React

Ctrl+Shift+R opens the message's reactions (or, on a missed call, calls back). The list has 12 quick reactions; you select one to react, your current reaction comes marked, and selecting it again removes it. The left and right arrows change the emoji's skin tone. At the end, "Add more reactions" opens the full emoji picker. The reactions you use most start to appear among the 12, with the most used on top. If you prefer fixed positions, use Settings > Interface > Reactions: "Use fixed quick reactions" and, in each position, Enter opens the picker to choose its emoji; "Restore default positions" undoes it. A dedicated sound plays when someone reacts to your message (Settings > Event sounds). Alt+Shift+E reads aloud the recent reactions the focused message received.

Star and pin

  • Star (Ctrl+Shift+O): stars are synced with WhatsApp, and each change is verified. To send your old local stars to WhatsApp, use "Sync old local stars with WhatsApp" in the chat menu.
  • Pin a message (Ctrl+Shift+P, when you are not recording): a button in each chat lists the messages pinned on WhatsApp, including old ones; Enter takes you to the message in the history. When you open the chat, the number of pinned messages is announced without changing focus.

Bookmarks

Bookmarks are positions you create on messages to come back to later. With the message focused, Ctrl+0 to Ctrl+9 creates a bookmark (or, if that number already exists, goes to it); Ctrl+Shift+0 to 9 removes it. Alt+Shift+0 to 9 creates temporary bookmarks, deleted when you leave the chat; Ctrl+Alt+Shift+0 to 9 removes the temporary ones.

Quick chats

With a chat focused in a chat list or open, press Ctrl+Alt+Shift+F1 to F10 to assign it to a quick slot. Ctrl+Shift+the same function key opens it from anywhere in the main window. F1 to F9 are slots 1 to 9; F10 is slot 0. Assignments are separate for each account and persist after restart. You can change these shortcuts in Settings, User Interface, Keyboard shortcuts, or assign a chat from its context menu. Protected chats cannot be assigned.

Search in the chat

Ctrl+Shift+F opens the search. F3 goes to the next result and Shift+F3 to the previous one, from anywhere in the open chat; focus follows the result and the screen reader announces the position. The "Previous result" and "Next result" buttons also work, and inside the search field Enter and Shift+Enter do the same.

Links

A message with two or more links becomes a navigable list. Enter or Space on a link opens it; Ctrl+C copies the link; the context menu has "Open link" and "Copy link". Group invitation links (chat.whatsapp.com/...) open WinZapp's "Join group by link" window, with the group preview, instead of the browser; the link's menu also offers "Join group by link" and keeps "Open link" for those who want the browser. Messages you send also carry a link preview.

In a link preview, the title and description appear with the real characters, without HTML codes such as &amp; or &eacute;, both in the preview WinZapp sends and in the one you read.

Contacts, polls and cards

  • Received contact card: Enter or Space saves it as a contact. The context menu has see name and number, copy the number with Ctrl+C, and chat. If the card has more than one number, WinZapp asks which one to use.
  • Received polls: the row reads the question and then each option, with percentage and votes when WinZapp receives them. Enter opens a window with the same list, check boxes to vote and a progress bar per option. In a single-answer poll, Tab from the message leads to the options and checking one already votes. The "View votes" button (Alt+V) lists who voted for what. To create a poll, see the Attachments section.
  • Order messages: Enter opens the order; see the Businesses section.
  • Community announcements: in the menu of an announcement message, "Community announcement replies" opens a window to read and send replies and refresh the list; the text is kept if the send is not confirmed.

Chat with Meta AI

WhatsApp requires accepting the Meta AI terms of service before the first message. WinZapp shows the terms, with a link to read them, and records the acceptance.

Select messages and bulk actions

Drafts, sending again and the controls after the list

The message field keeps what you typed with its conversation: leave a conversation without sending, and the text, mentions included, comes back when you open it again. In Settings > Interface > Chats, "Unsent message when you leave a conversation" chooses among keeping it in the field for the next conversation, keeping it as that conversation's draft (the default) or discarding it. Drafts last until WinZapp is closed.

A message of yours that failed or was not confirmed, text or attachment, has "Try sending again" in its menu, also with Ctrl+Shift+Y. WinZapp never resends anything on its own.

During playback, Tab after the message list stops at the speed button and the duration bar, and on a voice message, picture or video, at the online AI button. Each can be taken out of the way: "Hide the speed button while media plays (the speed shortcuts still work)" and "Hide the duration bar while media plays (Tab skips it)" in Settings > Audio > Audio playback, and "Hide the online AI button after the message list (the message menu still offers it)" in Online AI: Transcriptions and Descriptions. The shortcuts and the message menu keep working.

📎 5. Attachments and media

Photos, videos, audio, documents, contacts and polls are sent from the attachment menu; received media is opened, saved and described right in the message list.

Send attachments

Ctrl+Shift+A opens the attachment menu. The types are photos, videos, audio, documents, contact and, last, Poll.

  • Size: documents up to 2 GB; photos, videos and audio up to 1 GB, which are WhatsApp's limits.
  • Caption: the caption field takes several lines. Enter sends the attachment with its caption; Shift+Enter or Ctrl+Enter start a new line.
  • Audio files: a stereo or surround (5.1, 7.1) WAV or OGG Vorbis arrives with all channels, as ordinary audio, and keeps the sample rate up to 48 kHz. A file with more than 8 channels is sent unchanged as a document. Audio files pasted into the message field with Ctrl+V can go as audio or as a document (Settings > Audio; the default is audio).
  • Attach contact: the list opens with the search field focused, filters by name (including surname) and number, and has no duplicates.
  • Receiving a contact: an attached contact you receive shows the name and the number, which you can read, copy and use to chat with the person.
  • Poll: choose Poll and enter the question, up to 12 options and whether multiple answers are allowed.
  • Sent documents already show the file size in the list; while a document is downloading, the row shows progress, for example "35% (13.8 MB of 39.4 MB)".
  • Downloaded files always have the same size as the original, including those whose size is a multiple of 16 bytes, such as an APK, which Android installs normally.

Open, save and describe

On a message with media, Enter opens it (photo in the viewer, audio and video play, document opens in the default program). Space plays and pauses audio and video, but never opens links, documents or the viewer. After "Open" there are the buttons, reachable with Tab, "Save as..." (Ctrl+Shift+S), "Show in folder" (Ctrl+Enter, when you saved a copy) and "Describe" (Ctrl+Shift+I, when the AI features are on). The context menu has the same items.

A video message (the video recorded with the camera button in WhatsApp, sent instead of a voice message) appears in the list as "video message" and works like any video: Enter plays it, and Save as, the duration and the rest of the menu are the same.

The folder where the save windows open is chosen in Settings > Storage: the last folder used, Downloads or a folder of your own.

Media viewer

A viewer in its own window (if you turn it on in the settings for chat videos and statuses) has play and pause, forward and back 10 seconds (Alt+A and Alt+V), position, volume and speed. Ctrl+Shift+S saves and Ctrl+Shift+I describes.

Media tab

In Chat info and Group info, the Media tab lists photos, videos, audio, voice messages, documents and links, with a filter by type and by downloaded or not downloaded, loading of the full history, and the actions open, save as and delete on each item. Audio and voice messages are separate filters.

Automatic download

In Settings > Storage, "Automatically download media" turns on media download, and you choose the types. Unchecking it stops what is in progress; checking it (or checking one more type) starts downloading right away and also applies to the media of messages that arrive while WinZapp is open. Even with everything off, opening a media item manually downloads it right then. "Download media" (Sync menu, Ctrl+Alt+Shift+B) triggers the download whenever you want. WinZapp announces progress by voice, such as "Downloading media: 30 of 120 processed (8 downloaded)".

Settings > Storage > "Media cleanup" frees disk space by deleting the downloaded media files of the conversations you choose; the messages stay. You pick the conversations (with a "Select all" row and a groups/individual filter), the media types (photos and stickers, videos, audios, voice messages, documents) and a minimum size in MB. "Gather data" only reads and tells how many files and how many MB match, per type; "Proceed with cleanup" asks for confirmation (No is the default) and then deletes exactly what was previewed. Files you saved with Save As are never touched, nor are the media of unsent messages or locked chats. The cleaned files are remembered, so automatic downloads and syncs do not fetch them again, and an explicit download says so; only a logout or a new pairing forgets them, not F5.

📞 9. Calls

You can make, answer and decline voice and video calls right in WinZapp, without picking up your phone.

Neonize call audio includes fixes for silence after answering, lost audio frames and distortion during sample-rate conversion. Codec selection follows WhatsApp automatically; there is no codec switch to configure. This experimental engine still needs real-call quality evaluation; equal quality to other calling apps is not guaranteed.

Neonize keeps its normal call audio mode by default. A developer-only experimental 48 kHz path is available for calls negotiated with Opus; it does not change the MLow codec or add a control to the call window. Updating does not enable it automatically.

Make a call

In an individual chat, use the "Voice call" (Ctrl+Shift+V) and "Video call" (Ctrl+Alt+Shift+V) buttons; the shortcuts also work with the message field focused. The screen reader announces when the call connects, when it is reconnecting and when it ends.

WhatsApp only allows calls to groups of up to 32 participants. In a larger group, a "Calling is not possible" button with the note "The group has more than 32 participants" replaces the call buttons, and the call shortcuts say the same.

In a group chat the same buttons call the whole group. An incoming group call rings, is announced by the group's name and is answered like any other call, and the camera can be turned on during the call. WinZapp finds the camera with the FFmpeg it ships, so a video call no longer goes out receive-only. A group call that rang and you did not answer stays in the group's history, as a missed group call.

With Neonize, voice, video and group call buttons appear only for the call types the engine reports as supported. Until that information arrives, these buttons stay hidden; they update automatically when it arrives. The same check applies to joining an ongoing group call from its chat. An update never brings a hidden chat or an inactive window into focus.

With the Neonize engine, WinZapp itself plays the sounds WhatsApp Web used to play for you: while the other phone rings you hear the ringback tone with the pitch and rhythm of the country you called, and short beeps play while the call connects or reconnects. With the WPPConnect engine nothing changes. When an answered call ends, it also plays the WhatsApp call-ended sound; this is the "Call ended" sound event, which can be turned off or replaced in Settings > Sound events.

With the Neonize engine, a call you place that nobody answers ends by itself after one minute, as in WhatsApp Web: the ringing stops and the outcome is "not answered".

Call settings

In Settings > Calls, "Call audio settings" chooses microphone and speaker, and "Call video settings" chooses the camera. There you also find echo cancellation (reduces the return of your own sound when you use a speaker), microphone noise reduction and exclusive mode for microphone and speaker.

Echo cancellation comes turned on. It uses the same echo canceller as Google Meet and WhatsApp (WebRTC's), so you can talk through a laptop speaker or with a mixer's loopback turned on without the other person hearing their own voice. With headphones it does no harm; uncheck it only if you prefer.

WinZapp automatically converts call audio when the selected microphone or speaker uses a different sample rate from the call. Timing stays continuous between audio packets; no additional option needs to be enabled.

💡 If the call does not start
When the WhatsApp Web version in use does not support calls, WinZapp says so and what to try: restart WinZapp or choose Help > Force reinstall WPPConnect.

When WPPConnect is reinstalled, WinZapp preserves a newer compatible WhatsApp Web catalogue and checks for a fresh one. Without internet, a usable catalogue is retained, but its freshness cannot be confirmed. If a call still cannot start, restore internet access and restart WinZapp. A confirmed VoIP mismatch that cannot be retried is reported without repeating initialization.

While a group chat is open, WinZapp checks for an ongoing call about every ten seconds. A join button appears only when a call is available and disappears when it ends. Joining a video call starts with the camera off. Joining an existing call does not use the 32-member limit for starting a new group call. While a call is available, the "Join ongoing voice call" button or, for a video call, "Join ongoing video call (camera off)" replaces the voice and video start buttons. In Calls (Alt+6), the Ongoing filter lists joinable calls, including multiparty calls outside group chats; they also appear first in All. Select a call and press Enter or use the same join button. If you are already in that call, the button is "Return to call" and brings your current call window forward. The list refreshes about every ten seconds while Calls is open and includes only calls WhatsApp makes available to your account.

Use the "Call participants" button in the call window, or on a selected ongoing call in Calls, to see the connected people by name. The list updates every ten seconds; "Refresh" updates it on demand and "Close" or Esc closes it. Invited and disconnected people are excluded. Reading the list does not join or end a call.

🔒 11. Locked chats

Locked chats (Alt+7) stay in a vault protected by a PIN, outside the chat list, the archived chats, the search and the forward window.

  • Lock: "Lock chat" in the context menu or Ctrl+Shift+T. The PIN has 6 to 12 digits. When you set up the vault, WinZapp creates a recovery key (it can be read aloud or copied) to set a new PIN if you forget the current one.
  • Notifications: those of these chats only say how many new messages arrived, with no name or content. Their messages are never transcribed automatically, and online AI asks again for every send.
  • Closing the vault: it closes by itself when you minimize WinZapp, hide it in the tray and switch panels, and (if you want) after a period of inactivity. Ctrl+Shift+K closes and hides the vault right away.
  • Secret code: "Locked chats" can be taken out of the navigation menu; in that case, the vault opens by typing a secret code in the chat search. This is set up in Settings > Interface > Chats > Locked chats.
  • WhatsApp Chat Lock: chats locked on the phone are also hidden in WinZapp and only show in Locked chats, after your PIN (if you never created one, WinZapp offers to create it). Only the phone can unlock them; a chat unlocked on the phone goes back to the list by itself.
  • Bulk actions: locked chats can also be selected to unlock or mark as read/unread.

👤 13. Accounts, tray and sync

Multiple accounts

Each account has its own window and its own local server. The Accounts menu switches between them; so does Ctrl+Alt+1 to 9. "Close current account" (Ctrl+F4) ends only the account you are in, frees its memory and connection, and moves to another open account. To open it again, choose it in the Accounts menu of another account or use Ctrl+Alt with its number. If it is the only one open, WinZapp asks first, because closing it ends the program.

Deleting an account (Accounts > Manage accounts, Delete button) removes everything it owns: messages, media, settings, the browser profile that holds the WhatsApp login and that profile's backups. Anything that cannot be removed right away is finished the next time WinZapp starts. When the account is the only one, it can be deleted too: WinZapp asks for confirmation (No is the default), closes, and the next start is a first run.

Sync

  • F5 deletes and downloads all chats again (asks for confirmation, with No as the default and "Don't show again").
  • Shift+F5 resyncs only the open chat: it fetches the messages again, puts back in place the ones that were missing and removes the ones that no longer exist, without touching older history. It says whether the chat is already up to date or whether WhatsApp has no messages for it. It also asks for confirmation.
  • Progress is spoken every few seconds and shown in the window title: "Syncing chats: 12 of 80" and "Downloading media: 30 of 120 processed (8 downloaded)". Each announcement can be turned off in Settings > Accessibility > Spoken content; the option "Announce sync, media downloads and automatic offline mode" controls the announcements, which are not spoken while WinZapp starts in the background or during a call.
  • Offline mode (Ctrl+Alt+Shift+O) puts WinZapp offline; it also goes in and out by itself depending on the connection. When the computer wakes from sleep, WinZapp reopens the connection and fetches the new messages.
  • In a chat whose oldest messages exist only on the phone, WinZapp says "Use WhatsApp on your phone to see older messages."

Tray and notifications

In Settings > General > Notifications, "Background notification content" has three levels: sound, chat name and message text; sound and chat name, without the text; or sound only, with no on-screen notification and nothing read. Notifications respect Windows Focus Assist, and reading a chat inside WinZapp removes its notification from the notification area.

Connection and recovery

The connection to WhatsApp is stored in the internal browser's profile. WinZapp keeps backups of it (Settings > Storage > Profile backup) and restores them by itself when the connection is refused, saying aloud that it restored and is reconnecting; it only asks you to pair again when there is no usable backup. If the internal browser is incomplete (usually an antivirus removed part of it), WinZapp says so and explains what to do.

If WhatsApp disconnects the session, WinZapp tells you right away and opens pairing. In Settings > Connection you can use a custom API (remote server); in that case, the browser profile and the backups are left to the server.

💾 16. Backups and logs

Profile backup

The internal browser's profile is where your WhatsApp connection lives. In Settings > Storage > Profile backup:

  • Set how often WinZapp renews the backup when closed (default: 24 hours; 0 does it on every close).
  • Turn on the backup also while WinZapp is open, at the interval you choose. WhatsApp stays disconnected while it is made, which can take a few minutes, and WinZapp can ask before each time. The new backup only replaces the previous one after WhatsApp connects again with it.
  • "Don't keep profile backups" saves space but, if the profile gets damaged, you will have to pair again. When you check it, WinZapp says how much space the backups take and asks whether you want to delete them.

These backups are what WinZapp uses to recover by itself (see the Accounts, tray and sync section). To keep your message and media history, copy the data folder.

Logs

The logs of WinZapp (log.log) and of the local server (wppconnect.log) mask phone numbers, WhatsApp identifiers and contact names, so they can be sent when reporting a problem without exposing your contacts. They are in data\accounts\<account id>\logs, inside the WinZapp folder. log.log is replaced on every start. For problems with being asked to pair again or losing the session, also send shutdown_audit.log.

In Advanced, the "Export this account's logs..." button saves, in the background, a .zip file with the current account's logs and the Neonize bridge's, and announces when it finishes.

Report problems and request features in the repository's Issues (github.com/gabrielhhaber/WinZapp_Python/issues). Help > About the program shows the version, which the bug form asks for.

🍎 17. WinZapp on the Mac

On macOS, WinZapp works with VoiceOver. The chat and message lists are tables VoiceOver reads, and shortcuts follow the Mac rule: Ctrl becomes Command, Alt becomes Command-Option and Ctrl+Alt becomes Control-Command.

  • Lists: VO+Space on a row does what Enter does; on a chat, the chat opens and VoiceOver moves to the message field. The items of the row's context menu are VoiceOver actions (VO+Command+Space), and VO+Shift+M opens the context menu. VoiceOver keeps its place when a row changes, for example when a new message arrives.
  • Updates: "Check for updates" is in the WinZapp menu, under About WinZapp, and in "Help". With "Automatically check for updates" on in Settings, an update is downloaded in the background and installed when you quit WinZapp; if WinZapp stays open, the update window offers to install and relaunch, and WinZapp announces it by speech and by a notification. The update window says what changed since your version. Installing an update takes a few seconds, and the first launch after it is as quick as any other.
  • Update verification: If verification fails, the message explains whether the update verification file could not be retrieved or the official release tag could not be checked. It distinguishes connection, address lookup, timeout, certificate, access, missing resource, server and GitHub request-limit problems. Temporary connection and server failures are retried once within the request time limit. When GitHub specifies a wait, the message gives the number of seconds; wait before checking again. Request limits stop further requests to that host in the same running process during that wait. A certificate failure or an unverified release is never accepted as a successful check.
  • Home and End: go to the first and last row of a list. After sleep: when the Mac wakes, WinZapp reconnects on its own.
