Exportar e importar configurações

No menu Arquivo, "Exportar configurações..." grava as suas preferências num arquivo e "Importar configurações..." aplica esse arquivo na hora, sem reiniciar. Serve para levar tudo para outro computador ou outra conta. A conexão com o WhatsApp e o que é próprio de cada conta (conversas limpas, sons por conversa) não vão no arquivo. Se você usa uma API própria, endereço, porta e chave vão junto.

Se mudar o idioma e aplicar, todas as opções passam para o idioma novo na hora.
