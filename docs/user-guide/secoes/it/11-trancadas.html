Locked chats (Alt+7) stay in a vault protected by a PIN, outside the chat list, the archived chats, the search and the forward window.

  • Lock: "Lock chat" in the context menu or Ctrl+Shift+T. The PIN has 6 to 12 digits. When you set up the vault, WinZapp creates a recovery key (it can be read aloud or copied) to set a new PIN if you forget the current one.
  • Notifications: those of these chats only say how many new messages arrived, with no name or content. Their messages are never transcribed automatically, and online AI asks again for every send.
  • Closing the vault: it closes by itself when you minimize WinZapp, hide it in the tray and switch panels, and (if you want) after a period of inactivity. Ctrl+Shift+K closes and hides the vault right away.
  • Secret code: "Locked chats" can be taken out of the navigation menu; in that case, the vault opens by typing a secret code in the chat search. This is set up in Settings > Interface > Chats > Locked chats.
  • WhatsApp Chat Lock: chats locked on the phone are also hidden in WinZapp and only show in Locked chats, after your PIN (if you never created one, WinZapp offers to create it). Only the phone can unlock them; a chat unlocked on the phone goes back to the list by itself.
  • Bulk actions: locked chats can also be selected to unlock or mark as read/unread.
