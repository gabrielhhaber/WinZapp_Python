Resumen de almacenamiento

Abra Configuración → Almacenamiento → Gestor de almacenamiento. Use Tab entre controles y Ctrl+Tab entre pestañas. En la lista, las flechas mueven el cursor y Espacio cambia la casilla; mover el cursor no selecciona un archivo para eliminarlo. Cada página contiene hasta 200 elementos. Analizar y actualizar no aplican la limpieza.

Tamaños lógicos, contados una vez por identidad de archivo. No se miden el espacio asignado ni el espacio libre del disco. Los archivos retenidos siguen ocupando espacio. Esta medición solo cubre esta instalación.

Preferencias

Todo el trabajo en segundo plano es opcional. Guardar preferencias no aplica una vista previa de archivos. El objetivo es orientativo, no una cuota estricta. No se impone un umbral de espacio libre en disco. La asociación opcional lee los historiales locales de mensajes seleccionados. Los modelos externos y las otras cuentas son solo informativos. Para incluir nuevas carpetas de cuentas, desactive y reactive ese ámbito.

Si la asociación de toda la cuenta es incompleta, seleccione menos chats locales. La asociación lee el historial local sin contactar con WhatsApp. El contenido enviado, pendiente, fallido, destacado, bloqueado, oculto o no asociado sigue protegido. Los botones de modelos y copias de seguridad abren sus ajustes existentes.

Protecciones

La protección prevalece sobre la selección manual y las reglas. La protección compartida abarca las cuentas de esta instalación. Quitar una protección no selecciona archivos. Los elementos ausentes o sin nombre visible conservan una etiqueta numérica privada.

Proteger archivos seleccionados → Proteger chats seleccionados → Actualizar protecciones

Archivos retenidos

La retención mueve la copia local sin crear otra y no libera su espacio. Restaurar nunca sobrescribe un archivo actual. La eliminación permanente no se puede deshacer aquí. El archivo multimedia podría no estar disponible en WhatsApp.

Para eliminar permanentemente archivos multimedia retenidos, active su asociación y seleccione chats en Preferencias, guarde y vuelva a intentarlo. Solo se pueden eliminar archivos actualmente visibles, desbloqueados, completamente asociados y sin protección.

Actualizar archivos retenidos → Restaurar archivos retenidos seleccionados → Eliminar permanentemente archivos retenidos seleccionados

Para una foto, vídeo, documento o audio limpiado, seleccione su mensaje y use Descargar. Confirme la solicitud independiente de esa copia. Esto no deshace la limpieza ni garantiza que WhatsApp tenga el archivo. No se quita otro bloqueo de descarga.

¿Eliminar registros vacíos de operaciones de hace más de dos días? Se conservan los archivos retenidos y los registros activos de recuperación. Las vistas previas caducan al cabo de un día.

Reglas

La antigüedad y el tamaño son condiciones, no pruebas de inutilidad. La protección prevalece. Una regla de sugerencia o notificación prevalece sobre una automática para el mismo archivo. El modo automático solo se ofrece para caché de compilación regenerable verificada.

El análisis manual no ejecuta eliminación automática. Solo una regla de caché activada por separado puede eliminar archivos en lotes limitados durante evaluaciones guardadas de inicio o intervalo. Pausar evaluaciones conserva otros borradores sin guardar. El objetivo usa la última medición no cancelada y no es una cuota de disco. Las solicitudes manuales y los envíos siguen disponibles.
