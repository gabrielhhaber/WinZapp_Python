Storage summary

Open Settings → Storage → Storage manager. Use Tab to move between controls and Ctrl+Tab between tabs. In the file list, arrows move the cursor and Space changes the checkbox; moving the cursor does not select a file for removal. A page contains at most 200 items. Scan and refresh do not apply a cleanup plan.

Logical file sizes, counted once per file identity. Allocated space and free disk space are not measured. Held files still occupy space. This snapshot covers this installation only.

Preferences

All background work is optional. Saving preferences does not apply a file preview. A target is advisory, not a hard quota. No disk-free-space threshold is enforced. Optional matching reads selected local message histories. External models and other accounts are information only. Newly added account folders require disabling and re-enabling that scope.

If matching an entire account is incomplete, select fewer local conversations. No model or backup removal is offered here; their buttons open the existing settings.

Protections

Protection wins over manual selection and rules. Shared protection applies across this installation's accounts. Removing protection grants no new selection. Missing or currently unnamed items keep a private numbered label.

Held files

Holding moves a local copy without making another copy and does not free its space. Restore never overwrites a current file. Permanent removal cannot be undone here. Media may be unavailable from WhatsApp.

Refresh held files → Restore selected held files → Permanently remove selected held files

For a cleaned photo, video, document or audio item, select its message and use Download. Confirm the separate one-copy request. This is not an undo or a promise that WhatsApp still has the file. No other download block is cleared.

Remove empty operation records older than two days? Held files and active recovery records are kept. Previews expire after one day.

Rules

Age and size are conditions, not proof of uselessness. Protection wins. A suggestion or notification rule wins over an automatic rule on the same file. Automatic mode is available only for verified regenerable compile cache.

Manual scans do not run automatic removal rules. Only a separately enabled cache rule can remove files during saved startup or interval evaluations, in bounded batches. Pausing scheduled evaluations preserves other unsaved drafts. A usage target uses the last non-cancelled measurement and is not a disk quota; manual requests and sending remain available.
