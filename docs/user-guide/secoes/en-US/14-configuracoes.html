Export and import settings

In the File menu, "Export settings..." saves your preferences to a file and "Import settings..." applies that file right away, without restarting. It is useful for taking everything to another computer or account. The connection to WhatsApp and what belongs to each account (cleared chats, per-chat sounds) are not in the file. If you use your own API, address, port and key go along.

If you change the language and apply, all options switch to the new language right away.
