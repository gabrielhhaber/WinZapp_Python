Arabic is now available in Settings > General > Language, with Arabic text in the Windows installer and uninstaller.

File > Settings (Ctrl+,) has a search field at the top and a list of categories. Type in the search field and press the down arrow to go to the results; Enter or Space opens the option found. Without a search, the arrow keys change category and Tab enters its options. In some categories, buttons open the window of one subject (such as Messages or Spoken content). Change what you want and use Apply or OK. In Interface, the Keyboard shortcuts button lets you change any shortcut.

Export and import settings

In the File menu, "Export settings..." saves your preferences to a file and "Import settings..." applies that file right away, without restarting. It is useful for taking everything to another computer or account. The connection to WhatsApp and what belongs to each account (cleared chats, per-chat sounds) are not in the file. If you use your own API, address, port and key go along.

If you change the language and apply, all options switch to the new language right away.

Shortcut letters and keyboard shortcuts

Every control in Settings and in the windows it opens has a shortcut letter: Alt plus the letter the screen reader announces goes straight to the control, and no letter repeats within one window. In Interface > Keyboard shortcuts, the shortcuts are in a tree by category: Right arrow opens a category and Left arrow closes it. The "Search shortcuts" field above it filters the tree; Down arrow goes from the field to the results, and Up arrow on the first one goes back to the field.

In the shortcut search, press the keys of a shortcut in the keys field to filter the tree by the commands that use that combination; WinZapp announces how many were found, and a button clears the search. The tree is built only once when Settings opens, does not announce selections while you type, and after applying changes focus goes to the OK button; Esc closes the window.

Advanced

The Advanced category, at the end of the list, has "Log level" (debug, information, warnings and errors, or errors only), applied at once; "Start the local API on a fixed port", with the port number, which applies the next time WinZapp starts and lets two copies of WinZapp run or avoids port 6300 when another program already uses it; and "Show every WPPConnect Server update, not only the ones the WinZapp maintainers checked", off by default, which also offers releases the maintainers have not checked yet, with a warning. The port of the Connection category is the custom API's and is enabled only with it.
