The main window is divided into panels. You can go to any of them from anywhere in the window with Alt+number.

ShortcutPanel

Alt+2Last message of the open chat
Alt+3Unread messages of the open chat

Alt+6Calls
Alt+7Locked chats

Alt+MMessages: goes back to the message list of the open chat
Alt+NFocuses the main navigation menu (the letter comes from the label in the program's language)
F1Shows all keyboard shortcuts
Ctrl+,Settings

The panels are also in a navigation list (Alt+N takes you to it), in the same order: Communities comes after Calls alpha 4397, with Alt+8 in the item's name, and you can reach it by moving down the list.

If no chat is open, Alt+2, Alt+3 and Ctrl+W say "No chat is open"; in an empty chat, Alt+2 says "This chat is empty".

The open chat stays "behind" the panels

When you switch panels (Status, Calls, archived...), the open chat stays open, just hidden. While it is hidden, its new messages are announced as coming from another chat and are not marked as read, and "typing" notices are not spoken. Go back to it with Alt+M, Alt+2 or Alt+3, or by opening it again.

System tray and global shortcut

WinZapp can stay in the system tray and start with Windows. There is a global shortcut (configurable in Settings > Interface > Keyboard shortcuts) that brings the window to the front from any program; with WinZapp already in the foreground, the same shortcut hides it in the tray. When started with Windows, it only shows up in the tray once the connection is ready.

Spoken announcements

Everything WinZapp says goes through your screen reader (or through the Windows SAPI voice, if you enable that option in Settings > Accessibility and no screen reader is active). In Settings > Accessibility > Spoken content you choose what is announced.
