On macOS, WinZapp works with VoiceOver. The chat and message lists are tables VoiceOver reads, and shortcuts follow the Mac rule: Ctrl becomes Command, Alt becomes Command-Option and Ctrl+Alt becomes Control-Command.

  • Lists: VO+Space on a row does what Enter does; on a chat, the chat opens and VoiceOver moves to the message field. The items of the row's context menu are VoiceOver actions (VO+Command+Space), and VO+Shift+M opens the context menu. VoiceOver keeps its place when a row changes, for example when a new message arrives.
  • Updates: "Check for updates" is in the WinZapp menu, under About WinZapp, and in "Help". With "Automatically check for updates" on in Settings, an update is downloaded in the background and installed when you quit WinZapp; if WinZapp stays open, the update window offers to install and relaunch, and WinZapp announces it by speech and by a notification. The update window says what changed since your version. Installing an update takes a few seconds, and the first launch after it is as quick as any other.
  • Update verification: If verification fails, the message explains whether the update verification file could not be retrieved or the official release tag could not be checked. It distinguishes connection, address lookup, timeout, certificate, access, missing resource, server and GitHub request-limit problems. Temporary connection and server failures are retried once within the request time limit. When GitHub specifies a wait, the message gives the number of seconds; wait before checking again. Request limits stop further requests to that host in the same running process during that wait. A certificate failure or an unverified release is never accepted as a successful check.
  • Home and End: go to the first and last row of a list. After sleep: when the Mac wakes, WinZapp reconnects on its own.
