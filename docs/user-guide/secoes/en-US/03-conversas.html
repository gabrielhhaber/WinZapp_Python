The chat list (Alt+1) shows the names of people and groups, never internal codes. Each row reads the name, the last message and the state (unread, pinned, muted...).

Filters and lists

  • Filters: All, Unread, Groups and Individual, as radio buttons. Alt+Shift+F takes you to them; Alt+Shift+A, Alt+Shift+U, Alt+Shift+G and Alt+Shift+I pick All, Unread, Groups and Individual straight from the list.
  • WhatsApp lists: your custom lists appear before the filters. You can refresh them, filter by them, create or rename a list, and add or remove chats, in "Manage WhatsApp lists". Editing depends on your account's support; when it is not possible, the manager says why. Locked chats or chats unavailable locally do not show in the selection, and the other members of the list are preserved.
  • Search: Ctrl+F takes you to the search field; the down arrow goes to the first result. In Settings > Interface > Chats, "Keep the chat search when opening a chat" makes Esc return focus to that chat in the results instead of going back to the full list.

Open a chat

Enter opens the selected chat. Focus goes where you set it in Settings > Interface > Chats (message field, or the unread marker / last message). Esc or Ctrl+W closes the chat.

ℹ️ Shortcuts can be changed
All shortcuts in this guide are the factory ones. You can change them in Settings > Interface > Keyboard shortcuts. The complete, always current list is in the Keyboard shortcuts section and on F1.

Clear and delete

  • Clear chat asks whether to keep starred messages ("Keep starred messages", checked by default). Unchecked, starred messages are deleted too, including on the phone. It also applies to several selected chats and to archived ones.
  • The clear and delete confirmations have a "Don't show again" box, which only counts together with Yes. To be asked again, use the matching options in Settings > Interface > Confirmations. With the question turned off, clearing keeps starred messages.
  • Mark all chats as read (File menu, or Ctrl+Alt+Shift+M) asks first, with No as the default. It also has "Don't show again"; the option "Ask for confirmation before marking all chats as read" brings the question back.
  • Spoken confirmation: marking a chat read or unread, muting, archiving and pinning now say what was done, and marking several chats as read says how many.

New chat, group and contact

Ctrl+N opens "New chat". There you search for a contact (the field already has focus and filters by name, including surname, and by number as you type), start a chat by number, create a group, add a contact, join a group by link and open communities ("Communities" button).

If you type a Brazilian number with the extra 9 and WhatsApp uses the number without it, the conversation stays a single one: after the first message it uses WhatsApp's number.

In a new or empty personal chat, the line that says there are no messages also tells you that messages and calls are end-to-end encrypted and, if the chat has disappearing messages, how long they last.

Contacts: local or synced with the phone

When you add a contact (in Chat info, in New chat or from a contact message), there are two tabs:

  • Contact synced with the phone: saves the name on WhatsApp and in the phone's address book. It opens by default; if the number is already in the phone's address book, only this tab appears. Deleting a synced contact also removes it from WhatsApp and from the phone.
  • Local WinZapp contact: the name exists only in WinZapp.

Verified businesses you have not saved (banks, payment apps...) appear with the business's verified name. A name saved in your contacts always takes precedence.

The conversation, archived and locked chat lists use the full width of the list, so names and message previews are cut off only when the window is narrow.

Pinning

With "Keep pinned chats in a fixed order" (Settings > Interface > Chats), new messages do not change the position of pinned chats and the order is kept on restart. Turned off, pinned chats move up with new messages like the others.

Select several chats

Ctrl+Space marks or unmarks the focused chat. After the first marked item, Space alone marks and unmarks the following ones (selection mode; the screen reader announces when it turns on and off, and it turns off when nothing is marked any more). Shift+Down/Up Arrow extends the selection, Shift+Home and Shift+End mark up to the start or the end, and Ctrl+Shift+Space marks or unmarks everything. With something marked, the first Esc only unmarks. This also applies in archived and locked chats, in the message list and in the forward window.

Archived chats

Alt+4 opens the archived chats. They have their own search (Ctrl+F), the same selection and the same actions. An archived chat is not announced aloud when a new message arrives while the archived list is off screen.
